# 晨光笔记

一个单页静态演示项目，用来演示「自动开发助手」的完整交付：提需求 → 自动开发 → 检查 → 推送分支 → GitHub Pages 预览。

## 本地查看

直接用浏览器打开 `index.html` 即可，没有任何构建步骤，也没有外部依赖。

## 怎么算好的改动

- 打开页面就能看到效果，不引入框架、构建工具或外部资源。
- 样式改动优先复用 `style.css` 里 `:root` 的配色变量。
- 交付前用一个能跑的检查脚本验证需求（比如 `node check.mjs`），把命令和结果写进报告。

## 预览

推送到 `dev/*` 分支会自动部署到 GitHub Pages（见 `.github/workflows/preview.yml`）。
